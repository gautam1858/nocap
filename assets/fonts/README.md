# Bundled fonts

`jbm-regular.ttf` and `jbm-bold.ttf` are subsets of **JetBrains Mono**
(© JetBrains s.r.o., Apache License 2.0), covering Latin-1, punctuation and the
arrow/symbol glyphs the Probable Cause card uses. They are embedded so the card
renders identically to a PNG offline, with no system fonts required.

Regenerate with `npm run assets` (needs fonttools).
